# 页面恢复验证（2026-10-17）

## 实现

- `visual_navigation.py` 根据截图区分世界、城内、搜索、采集、出发、聊天、马车及队列收起。
- 每次导航需两帧状态与位置一致，窗口位置变化时丢弃旧观察；不使用游戏内存或游戏接口。
- 世界/搜索入口的YOLO漏检可由原始像素模板复核。已在世界时不要求“世界”按钮。
- 派队前模板超时最多恢复3次；退出识别到的面板、必要时回城重进，再重新读取队伍。
- 队列收起有专门箭头证据；队列连续读取失败可重置页面，恢复次数有上限。
- 出发确认失败改为持续复查，不重复点击出发；只有队列变化确认后才计入派队数。
- 未知画面等待并保存诊断，最多8次已验证导航动作；F8和前台检查仍立即停止。
- 当前游戏已解锁9、10级，补入两种原始像素标签，目标默认仍为7级。
