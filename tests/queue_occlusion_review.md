# 队伍遮挡恢复审查

## 审查范围

- 队伍栏缺行、遮挡和未知状态是否会授权补队。
- 导航目标识别、连续画面确认、窗口变化及停止中断。
- 回城操作是否真实发生，是否确认城内和返回世界地图。
- 派队结果不确定时是否可能重复点击出发。
- 打包 EXE 与模型加载、界面启动和 F8 停止。

## 修复内容

- 原回城模板在故障截图上的分数约 0.729，低于原阈值 0.92。补充标准 1600×900 界面的实图文字模板，使用 0.96 门槛及右下角限定区域，不降低原模板阈值。
- 请求回城重置时，未找到目标或点击后仍未确认城内，均不报告重置完成。
- 连续确认城内后才进入世界，连续确认世界画面后才计为完成恢复。
- 保留完整队伍识别、未知不派队、未确认出发不重复派队及恢复次数上限。
