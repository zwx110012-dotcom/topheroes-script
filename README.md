# Steam Top Heroes 日常助手

通过游戏窗口截图识别状态、使用鼠标操作的 Windows 采集助手。

## 核心功能

- YOLO ONNX 本地 CPU 检测与 OpenCV 模板识别，支持识别预览。
- 支持 3/4 队、1～10 级红水晶选择，提供单轮采集和持续补队。
- 识别空闲、行军、采集、返程状态及倒计时，按队伍变化确认出发。
- 可选公会马车监测，根据采矿倒计时退出监测并恢复补队；每次启动默认关闭。
- 处理弹窗、队伍栏折叠与遮挡后的页面恢复；回城重置须确认城内及重新进入世界地图。
- 标准游戏客户区 1600×900，检查窗口位置、尺寸和前台状态，支持 F8 立即停止。
- Windows EXE 与配套模型见 [Releases](../../releases/latest)；六个 `.onnx`/`.json` 模型文件放在 EXE 旁的 `models` 文件夹。

## 审查与验证

- 状态识别只使用截图；窗口接口用于窗口识别、位置、尺寸及前台检查。运行时不读取或修改游戏内存、不注入游戏进程。
- 识别坐标须还原到游戏客户区；窗口变化后废弃旧坐标，重新识别。
- 缺失或遮挡的队伍不当作空闲；出发结果未确认时不重复派队。
- 回城按钮连续确认后才点击；进入城内、再返回世界地图均经连续画面确认，才增加恢复次数。
- 相关回归测试 35 项通过；五张区域脱敏的故障截图回放通过。
- 本地完整测试结果：83 项通过、1 项跳过；另 7 项因历史原始截图未随仓库提供而未通过，未将其计为验证成功。
- 正式 EXE 的离线故障回放、界面启动、取消启动和 F8 停止检查通过；模型文件 SHA256 保持不变。
- 待实机验证：本次修复后的回城消除遮挡、完整返程补队、整夜稳定性、马车成功加入及其他电脑运行。

详细审查记录见 [队伍遮挡恢复审查](tests/queue_occlusion_review.md)。
